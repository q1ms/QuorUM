01 — Introduction

Project Overview & Recommendation

Quorum solves the "Lone Ranger" and "Free Rider" problems via a UM-verified, double-blind rating system.

Recommendation

Proceed with Quorum v1

The project is technically feasible, operationally viable, and economically sound (RM 10,945 budget). Scheduled for completion within 12 weeks.

Alternatives Rejected

Why Not Others?

WhatsApp/Forms lack verification. LinkedIn lacks academic context. Manual faculty assignment removes student autonomy.

System Description

Three Interfaces

1. Student Profile & Search.
2. Verification Engine (UM-verified).
3. Admin Dashboard for anomaly flagging.

02 — Feasibility Assessment

Assessment Areas

Evaluating the project across six critical dimensions.

Economic

RM 10,945 Budget

Manpower: RM 7,500
Server & DB: RM 1,800
Software & Domain: RM 450
Training & Contingency: RM 1,195

Technical

Proven Tech Stack

Next.js + React + Supabase. The team already possesses the required skills for this modern stack.

Operational

High Adoption

Web-based, no installation needed. Familiar LinkedIn-style UI. Supplements existing processes.

Legal

PDPA Compliant

User consent at signup. No public "free rider" badge (prevents defamation). Disputed ratings are excluded from aggregates.

Political

Faculty Alignment

Aligns with FCSIT goals of improving graduate attributes (accountability) and provides verifiable grading data to lecturers.
